### Project Description

**Am I Being Ignored?** is an aggressively useless chat-forensics web app that converts normal reply delays into a full emotional investigation. Paste or upload a chat, and the app calculates a fake-but-serious **Catastrophic Abandonment Index™**, prepares courtroom evidence, writes an obituary for the conversation, and triggers unnecessary panic for even the smallest delay.

It is not here to solve your life. It is here to overanalyze it with charts, decimals, emojis, and zero useful outcomes.

### The Problem (that doesn't exist)

People sometimes reply late.

Unfortunately, instead of doing something healthy like waiting, sleeping, studying, touching grass, or simply asking them directly, we spend hours performing imaginary investigations:

- “They replied after 47 seconds. Is this emotional distancing?”
- “They said ‘haha sorry’. Is this legally suspicious?”
- “They saw my message, but did not respond immediately. Should I prepare for social death?”
- “They typed ‘k’. Is my dignity recoverable?”

This project solves the completely unnecessary problem of **not having enough scientific-looking evidence for your overthinking**.

### The Solution (that nobody asked for)

We built the **Department of Unnecessary Grief**: a dramatic, sarcastically depressive, browser-based investigation system that treats ordinary chat delays like national emergencies.

The app parses conversations, detects reply gaps, unanswered questions, dry replies, double texts, effort imbalance, and emotional damage indicators. Then it produces:

- A six-decimal **Catastrophic Abandonment Index™**
- A reply-delay tragedy timeline
- Dignity depreciation metrics
- Situation-specific emotional damage reports
- Courtroom prosecution and defense arguments
- A full obituary for the conversation
- Five stages of unnecessary grief
- A fictional double-text risk simulator
- A final panic button for maximum uselessness

In short: we turned “maybe they are busy” into a complete bureaucratic funeral.

## Implementation

For Software:

### Installation

Clone the project or download the source ZIP:

```bash
git clone <your-repository-url>
cd am-i-being-ignored
```

No dependency installation is required for the final static version.

If you want to rebuild the single-file HTML bundle:

```bash
python3 build.py
```

If you want to run QA tests:

```bash
node --check app.js
node qa.js
node qa_obituary.js
```

### Run

Option 1: Open the final standalone file directly:

```bash
open am-i-being-ignored.html
```

Option 2: Serve locally:

```bash
python3 -m http.server 8080
```

Then open:

```text
http://127.0.0.1:8080
```

Option 3: Deploy as a static site using GitHub Pages, Cloudflare Pages, Netlify, or Vercel.

## Why This Is Useless

A useful app would help people communicate better.

This app does the opposite. It provides dramatic dashboards, fake legal evidence, emotional accounting, funeral paperwork, and financial-sounding dignity metrics for a situation that could probably be solved with one normal conversation.

That is why it is perfect for Useless Projects.

---

## Why This Can Win

This project focuses on the three things a useless-project demo needs:

1. **Instantly understandable joke**
   - Everyone understands the pain of waiting for a reply.
   - The app exaggerates it within seconds.

2. **Real implementation complexity**
   - Local parser
   - Feature extraction
   - Scoring engine
   - Charts
   - Canvas export
   - Sound generation
   - Multiple interactive modes
   - Responsive UI

3. **Commitment to the bit**
   - Every screen belongs to the same fake institution: the Department of Unnecessary Grief.
   - The app never becomes genuinely helpful.
   - Even the final action is panic, not advice.
